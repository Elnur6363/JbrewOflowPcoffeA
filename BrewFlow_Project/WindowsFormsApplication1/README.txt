BrewFlow — расширенная версия для Visual Studio 2022

Открытие проекта:
1. Распакуйте архив в обычную папку.
2. Если Windows заблокировала архив: правой кнопкой по ZIP -> Свойства -> Разблокировать -> Применить, затем распакуйте заново.
3. В папке BrewFlow_Код откройте WindowsFormsApplication1.csproj (файл решения .sln в этом проекте отсутствует).
4. В Visual Studio выберите Сборка -> Пересобрать решение, затем F5.

Добавлено:
- окно оформления заказа;
- выбор наличной оплаты, карты при получении или демонстрационной онлайн-оплаты;
- выбор самовывоза или курьерской доставки;
- проверка адреса доставки;
- сохранение способа оплаты и получения в истории заказов;
- дополнительные разделы: история, бонусы, доставка, отзывы, поддержка, оплата, профиль.

Важно: онлайн-оплата имитируется. Реальные деньги не списываются, банковские данные не запрашиваются и не сохраняются. Это учебная локальная программа без сервера и подключения к платёжному шлюзу.
